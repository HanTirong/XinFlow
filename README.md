## 项目简介

薪流是一款面向个人的工资流向记录 App。它不追求完整资产管理，而是专注回答：每期工资去了哪里，现在还剩多少？

工资周期由用户设置的固定发薪日确定。消费、存款和理财均视为工资去向，并共同影响本期剩余金额。

```text
当前剩余 = 本期工资 + 正余额结转 - 净消费 - 净存款 - 净理财
```

## 主要功能

- 按固定发薪日管理当前与历史工资周期
- 快速记录消费、存款和理财，支持一级与二级分类
- 查看本期工资剩余、发薪倒计时和最近流水
- 按日期、分类、备注和金额筛选流水，并对长列表分页加载
- 历史周期默认只读，可在明确确认后补记、修正和重新计算最终余额
- 通过关联退款或提取记录冲减原消费、存款和理财
- 手动选择是否将上期正余额作为独立金额结转
- 自定义分类图标、颜色、顺序、首页快捷项及二级分类归属
- 周期与分类预算、低余额、大额消费、临近发薪日和备份提醒
- 可选的安卓每日本地记账通知，时间可调整，点击后进入记账
- 查看分类占比、每日趋势、周期对比、跨周期平均值与长期变化
- 跟随系统、浅色和深色外观模式
- 本地数据统计、历史周期删除、全部清空与独立隐私说明
- 金额隐藏、最近任务遮挡、系统身份验证应用锁与自动锁定
- 导出 AES-256-GCM 密码备份，并兼容原有未加密 `.xinflow` 备份

## 技术栈

| 领域 | 方案 |
|---|---|
| 客户端 | Flutter + Dart |
| UI | Material 3 |
| 状态管理 | Riverpod |
| 数据库 | SQLite + Drift |
| 架构 | Repository + Domain Service |
| 备份 | JSON + ZIP + SHA-256 + AES-256-GCM |

金额在数据库和业务层统一使用整数“分”保存，避免浮点数精度问题。应用无需账号或服务器即可离线使用。

## 快速开始

环境要求：Flutter 稳定版、Dart 3.12 或更高版本，以及对应平台的开发工具。Android 构建当前使用 NDK `28.2.13676358`。

```powershell
flutter doctor -v
flutter pub get
flutter analyze
flutter test
flutter run
```

构建 Android 调试包：

```powershell
flutter build apk --debug
```
