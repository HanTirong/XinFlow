## 项目简介

薪流（XinFlow）是一款面向个人的工资流向记录 App。

它不以传统记账或完整资产管理为目标，而是围绕一个更明确的问题展开：每个月发下来的工资去了哪里，现在还剩多少？

薪流按照用户实际确认的“工资到账”划分周期，而不是在每月固定日期的零点自动切换。消费、存款和理财都会被视为工资的去向，并共同影响本期剩余金额。

```text
本期工资 = 净消费 + 净存款 + 净理财 + 当前剩余
```

## 核心特性

- 按实际工资到账时间管理工资周期
- 快速记录消费、存款和理财
- 随时查看本期工资剩余
- 流水查询、修改、软删除和补记
- 使用关联退款记录冲减原消费
- 查看完整工资周期报告
- 展示分类占比、每日趋势和周期对比
- 本地 SQLite 数据存储
- 跟随系统、浅色与深色三种外观模式
- 结构化备份与合并恢复
- Android 与 iOS 共用业务代码
- 无账号、无服务器也能完整使用

## 已确定的产品规则

### 上期剩余不自动结转

旧工资周期封存后保留最终剩余，新周期只以新到账工资作为初始金额。系统不会静默地把上期余额加入新工资。

### 退款独立记录

普通金额不接受负数。退款必须关联原消费，并作为独立退款记录冲减消费金额。

### 历史周期默认只读

封存后的工资周期只能查看。如需调整，必须进入明确的“修正历史周期”流程，修改后重新计算报告。

## V1 功能范围

V1 计划实现：

- 首次启动与发薪日设置
- 工资周期创建、封存和切换
- 首页余额与发薪倒计时
- 快速记一笔
- 一级、二级分类
- 当前与历史流水
- 工资周期报告
- 分类管理
- 本地备份、校验与合并恢复
- 数据库版本迁移

V1 暂不包含：

- 账号与云同步
- 银行、微信或支付宝账单自动读取
- AI 自动分类
- OCR 和语音记账
- 多账户与多币种管理
- 复杂预算与投资收益管理

## 技术方案

项目计划采用以下技术栈：

| 领域 | 方案 |
|---|---|
| 客户端 | Flutter + Dart |
| UI | Material 3 + 蓝色/蓝灰视觉体系 |
| 架构 | 轻量 MVVM + Repository + Domain Service |
| 状态管理 | Riverpod |
| 导航 | Material 3 NavigationBar + 模态编辑页 |
| 本地数据库 | SQLite + Drift |
| 报告图形 | Material 进度条与指标卡片 |
| 备份 | JSON + ZIP + SHA-256 |

金额将在数据库和业务层统一使用整数“分”保存，避免浮点数计算带来的精度问题。

## 页面结构

底部导航计划包含四个页面：

```text
首页｜流水｜月报｜我的
```

- **首页**：本期剩余、已分配金额、发薪倒计时、快速记账和最近流水。
- **流水**：查看当前及历史工资周期中的全部记录。
- **月报**：查看工资、消费、存款、理财、最终剩余和分类趋势。
- **我的**：发薪日、分类、备份恢复和其他基础设置。
